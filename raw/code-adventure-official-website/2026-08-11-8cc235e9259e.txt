What happens at camp
A real curriculum, taught by working tech mentors
Three days, six tracks, one student-built project. No prior coding experience needed — we start at the beginning.
Day 1
Wed · June 24
Cyber Security & Data
Spot real-world security threats, then dig into a live dataset to find patterns the way analysts do.
Cyber Security
Data Analytics
Day 2
Thu · June 25
Design & Build
Design a real app interface, then write the code that makes it work — start to finish in one day.
UX Design
Software Engineering
Day 3
Fri · June 26
Mystery Project & Showcase
Team up to build something brand-new combining everything from the week, then present it on stage.
Team Project
Live Showcase
