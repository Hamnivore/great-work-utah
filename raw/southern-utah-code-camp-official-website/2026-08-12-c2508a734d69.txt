What is Code Camp?
Code Camp is a programming, design, and entrepreneurship contest all rolled up into a ridiculously compressed 24-hour event. It’s crazy fun! Teams ranging in size from one to four participants compete against other teams to build the best web or mobile app.

When is Code Camp?
Friday, Nov 13 to Sat Nov 14, 2026
Code Camp consists of two key dates:
The Pre-Flight meeting and the actual Code Camp Event.
Pre-Flight: Thursday, Nov 12, 2026
It is strongly encouraged that individuals show up to the Pre-Flight in order to learn of the up-to-date rules, finalize teams and learn about key strategies on how to win.
