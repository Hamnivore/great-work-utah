## Summary

Code Adventure's own site for its free coding camp for girls. Unusually among the volunteer-run Utah
tech programs in this corpus, it publishes outcome figures and a multi-year host history, which makes
it the most substantively sourced of them — while still being the program describing itself.

## Useful Claims

- Code Adventure runs a **free** three-day coding camp for girls aged **13–18**, with no prior
  experience required. The 2026 June camp ran **June 24–26, 2026, 9am–3pm**, hosted at **nCino's
  headquarters in Lehi, Utah**.
- 2026 is described as the **fifth year running**, with past camps hosted 2022 through 2025.
- The curriculum is six tracks over three days: cyber security and data analytics (day 1), UX design
  and software engineering (day 2), and a team project plus live showcase (day 3).
- Mentor-to-student ratio is stated as approximately **1:7**, and mentors are described as working
  tech professionals.
- Reported outcomes: **300+ students** through camp, **97%** glad they attended, **95%** would
  recommend to a friend, **96%** better understand tech careers.
- Lunch, snacks, laptops, and swag are provided — so unlike Kids Code Camp, students need not bring a
  computer.

## Reliability Notes

Self-reported tier, and the outcome figures need reading carefully. "300+ students through camp" is
cumulative across prior camps, not per-year. The three percentages are satisfaction-survey results
reported by the organizer with no stated sample size, response rate, or instrument — they measure how
attendees felt, not whether the camp changed anyone's trajectory. The page presents them under the
heading "Real outcomes", which is a stronger word than the numbers support.

The host history shown for 2022–2025 remains self-reported by the organizer; host names were conveyed
through images and are not present in the extracted-text capture, so they are not asserted here.

No entity or EIN was located for Code Adventure; a search of the IRS Utah exempt-organizations extract
found no matching registration, so whether it is an independent nonprofit, a fiscally sponsored
program, or a company-backed initiative is unresolved.
