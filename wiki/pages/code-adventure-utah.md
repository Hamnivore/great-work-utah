## Summary

Code Adventure is a free, hands-on summer coding camp for girls. Code Adventure Utah provides a bounded benefit: Girls ages 13–18, including students with no prior coding experience.

## Who It's For

Girls ages 13–18, including students with no prior coding experience.

## What It Provides

The published curriculum covers cybersecurity, data analytics, UX design, software engineering, a team project, and a live showcase. The organizer reports approximately one mentor for every seven students ([official source](code-adventure-official-website.md)).

## How To Use It

Check the official site for the next announced camp and registration form. The captured page describes the June 2026 session; it does not establish future dates.

## Cost / Eligibility

The camp is free. For the 2026 session, lunch, snacks, laptops, and swag were included, and no prior experience was required ([official source](code-adventure-official-website.md)).

## Best Fits

Teen girls seeking a short, beginner-accessible introduction to several technology disciplines and a team project rather than a long-form course.
