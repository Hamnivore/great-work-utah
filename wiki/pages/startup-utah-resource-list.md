## Summary

The Startup State resource page presents a resource filter for Utah entrepreneurs. It invites users to search and filter resources by topic, stage, community, industry, and location, and includes routes to add a resource, download the resource list, print results, or email results.

## Useful Claims

- The page presents itself as the "Startup State Resource Filter" and is intended to help entrepreneurs
  find resources specific to their business.
- The filter dimensions offered in the dropdown are topic, community, industry, and location; general
  keyword search is offered as a fallback. (A "stage" dimension recorded at the 2026-05-09 fetch was not
  present on 2026-08-11.)
- The portal accepts resource submissions ("Add a Resource") and offers a downloadable resource list.
- A resource appearing in this directory establishes that **GOEO listed it**. It does not establish that
  the resource is currently operating, that its website works, or that its described services are
  available.

## Reliability Notes

**Read this before citing this page as a resource's only evidence — roughly 174 pages currently do.**

Self-reported tier, and one step further removed than most: GOEO is not the subject of the resources it
lists, so for any individual resource this is a *directory listing*, not a primary record. It is
excellent evidence that the State of Utah recognizes a resource, and no evidence at all that the
resource is alive. `business-technical-assistance-center.md` is the worked example: listed here, with a
website that has returned HTTP 500 since spring 2025, and an existence question that only the IRS
exempt-organization record could answer
([Source: IRS Exempt Organizations Business Master File, Utah Extract](irs-bmf-utah-exempt-organizations.md)).

The listing content is also dynamic — filters and entries change without notice, as the "stage"
dimension already has — so claims drawn from it need the fetch date attached, and any resource page
resting on it alone should be treated as `Confidence: Low` until a primary or provider source is added.
